## 🧭 Como eu trabalho

1. **Entender** o problema real, quem vai usar e o que o sistema precisa entregar
2. **Modelar** o banco de dados e as regras antes da primeira tela
3. **Construir** o back-end e a API primeiro: autenticação, permissões e dados sólidos
4. **Interface** limpa e direta para quem usa todos os dias
5. **Entregar** com testes, documentação (Swagger) e deploy real
