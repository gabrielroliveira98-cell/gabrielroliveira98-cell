## 🧭 Como eu trabalho

1. **Entender** quem vai usar e quais decisões a tela ou o dado precisa apoiar
2. **Organizar os dados** e definir os indicadores que realmente importam
3. **Desenhar a interface:** hierarquia clara, responsiva e acessível
4. **Construir** com código limpo, componentes reaproveitáveis e boa performance
5. **Entregar** com o projeto no ar, testado e documentado
